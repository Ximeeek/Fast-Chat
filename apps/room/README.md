# apps/room

Podprojekt dla aplikacji klienckiej pokoju czatu P2P projektu **FastChat Room**.

- **Technologia:** SvelteKit + WebRTC (planowana inicjalizacja w Fazach 6–11)
- **Przeznaczenie:** Anonimowy interfejs czatu, negocjacja połączeń P2P (WebRTC DataChannel), efemeryczny czat tekstowy oraz transfer plików w przeglądarce bez pośrednictwa serwera.
